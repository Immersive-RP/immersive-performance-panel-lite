Tuning dials

fast to reason about

Each option maps to a native call. No surprises — just clear cause and effect.

  • Ped Density → SetPedDensityMultiplierThisFrame
  • Scenario Density → SetScenarioPedDensityMultiplierThisFrame
  • LOD Distance → SetLodScale (clamped to 0.1–1.0)
  • Decals → SetDisableDecalRenderingThisFrame
  • Screen Blur → SetDisableScreenBlur
  • Artificial Lights → SetArtificialLightsState (global state)

Notes

keep it predictable
  • Artificial lights is global — if another resource manages lighting, whichever runs last wins.
  • Density/scenario multipliers are applied only while the panel is open; saved values restore on start.
  • Values are written on change; no extra menus, no extra layers.

FAQ

quick fixes
The panel won’t open

Confirm the resource started successfully. Rebind the key in keybind settings and test again. If it still won’t open, check the in-game console for NUI errors.

Values don’t persist

Persistence uses client-side resource KVP keys. Change a value, close the panel, reopen it, and confirm it stuck.

Artificial lights behave oddly

That toggle is a global lighting state. If something else also manages lighting, leave this off to avoid conflicts.
